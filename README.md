Desenvolvedor **full stack** e **Engenheiro Civil**. A engenharia me ensinou a entender bem o problema antes de começar a construir, e levo isso para o código: levantar requisitos, desenhar o processo e entregar algo que funcione na prática. Foi assim que nasceu o [PadrãoCerto](https://github.com/RafaelTeixeira1/padraocerto), um sistema de inspeção de qualidade para obras. Meu foco hoje são sistemas web com Laravel, React e Vue, além de apps mobile com Flutter. Também tenho experiência com **infraestrutura de redes e segurança**, o que me ajuda a enxergar a aplicação inteira, do banco de dados ao servidor onde ela roda.

- 🎓 Estudante de Bacharelado em Sistemas de Informação no **IF Goiano (Campus Ceres)**
- 🏗️ Construo sistemas que resolvem problemas reais, de um ERP comercial a um app para registrar focos de incêndio em campo
- 🐳 Uso Docker e GitHub Actions para padronizar ambientes e automatizar entregas

## ⚙️ O que já coloquei em prática

- **APIs seguras:** controle de acesso por perfil, auditoria de ações e limite de requisições no [Alumínio ERP](https://github.com/RafaelTeixeira1/aluminio-erp)
- **Operação e confiabilidade:** endpoints de health check e métricas, backup com verificação de integridade e CI no GitHub Actions
- **Testes e deploy:** testes com Jest e React Testing Library e hospedagem na AWS (EC2 e S3) no [Furniro Web](https://github.com/RafaelTeixeira1/furniro-web)
- **Mobile e geolocalização:** autenticação, banco em tempo real e mapas com Firebase e Flutter no [FireApp Mobile](https://github.com/RafaelTeixeira1/fireapp-mobile)
- **Infraestrutura:** redes segmentadas com firewall em iptables, DNS, DHCP e LDAP em containers no [Infra de Rede com Docker](https://github.com/RafaelTeixeira1/infra-rede-docker)
- **Segurança:** diagnóstico de vulnerabilidades, hardening de servidores e relatório forense no [Lab de Segurança](https://github.com/RafaelTeixeira1/seguranca-informacao-lab)
